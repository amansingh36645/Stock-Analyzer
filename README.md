# 📖 Overview

MarketPulse is a modern frontend web application designed to simplify stock market analysis through an intuitive and responsive interface.

The platform combines live stock information, interactive market dashboards, financial news, company fundamentals, and a unique **Prediction League** where users can predict stock movements and earn virtual points based on their accuracy.

Built with **React** and **Tailwind CSS**, MarketPulse focuses on delivering a fast, clean, and engaging user experience.

# 🚀 Installation

Clone the repository

```bash
git clone https://github.com/yourusername/marketpulse.git
```

Navigate to the project

```bash
cd marketpulse
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```
